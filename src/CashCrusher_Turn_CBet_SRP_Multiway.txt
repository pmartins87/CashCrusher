// Gate 02E — ordinary-SRP Turn CBet while 3+ players remain
// ============================================================================
// Scope:
//   Hero was ordinary-SRP PFA, actually executed a standard flop CBet and is
//   checked to / first to act on turn while at least TWO opponents remain live.
//
// Source hierarchy:
//   A/P — exact true3 BTN-v-SB+BB LAST shape uses the mature CrusherTBP
//         `3wBTNv2p` Turn-CBet gap-fill as nearest donor.
//   P   — other true3 FIRST/MIDDLE/LAST and every 4way+ origin/current field.
//   A   — mature DeepCrusher multiway philosophy corroborates value-heavy
//         fail-closed behavior where no exact source branch exists.
//
// Critical cash adaptations:
//   * current hand strength overrides stale flop class;
//   * prior multiway flop call selects continuing ranges;
//   * 4way+ origins/current fields tighten one-pair and semibluff barrels;
//   * deepest-effective SPR controls any field-wide low-SPR relaxation;
//   * TP/OP bet decisions never imply stack-off permission.
//
// OpenPPL safety:
//   flat complete WHENs only; no generic tail; no BetMax in this node.
// ============================================================================

// Purpose: completion/four-card turn where medium made value becomes more fragile.
// Source: DeepCrusher `turn_Completed` / `turn_SuperCompleted` and four-card
// completion caution throughout later-street logic.

##f$cc_turn_mw_srp_dangerous_runout##
f$cc_turn_new_completion || f$cc_turn_four_card_straight_or_flush || f$cc_turn_super_completed

// Purpose: clean turn for multiway one-pair value consideration.
// Source/Provenance: A/P complement of explicit dangerous runout family.
##f$cc_turn_mw_srp_clean_turn##
!f$cc_turn_mw_srp_dangerous_runout

// Purpose: favorable A/K pressure overcard without new public completion.
// Source: source v2p permits selected OC/gutshot pressure; exact six-max A/K
// selector is P and remains context-restricted below.
// Provenance: A concept + P six-max selector.
##f$cc_turn_mw_srp_high_pressure_turn##
f$cc_turn_mw_srp_clean_turn &&
f$cc_turn_overcard_to_flop &&
!f$cc_turn_pairs_flop_rank &&
(f$cc_turn_is_ace || f$cc_turn_is_king)
