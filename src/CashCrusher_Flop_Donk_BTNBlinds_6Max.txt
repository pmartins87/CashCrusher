// Purpose:
//   Adapt the high-ancestry `(BBorSB)v2pp` source shell to a hand that was dealt
//   4-6 handed but reached the flop exactly BTN+SB+BB.  Limped and BTN-open SRP
//   origins remain separate, and BB may exploit the extra fact that SB checked.
//
// Source boundary:
//   A = dedicated `(BBorSB)v2pp` source principles: multiway honesty, Axx/high
//       board caution, value/protection leads, 50/75/POT sizing ancestry.
//   P = all 4-6h range-frequency decisions below. Earlier-position folds change
//       BTN/blind ranges, so this file is NOT direct source coverage.
//   T = exact deal size, preflop chronology, Hero position, board/hand/SPR facts.
//
// Cash-depth contract:
//   * source low-SPR logic is reviewed rather than deleted;
//   * POT survives only for robust 2P+ value on draw-heavy deepest SPR <=1.25;
//   * one-pair hands and draws never inherit a future Turn jam from that sizing;
//   * no Donk-vs-raise defense is encoded here.
//
// Safety:
//   * no pure-air baseline;
//   * BTN-limp != BTN-open SRP;
//   * SB FIRST != BB MIDDLE-after-SB-check;
//   * no shortest-effective SPR, BetMax, HandPower, random or commitment helper.
// ============================================================================

// Source ancestry: native 3h source shape #2.

// Purpose: limped-pot BB acts MIDDLE only after SB has checked.
// Source/Provenance: T current first-Hero-action + canonical order; P distinct owner.
##f$cc_flop_donk_6max_limped_bb_context##
f$cc_flop_donk_6max_limped_context &&
f$cc_hero_pos_id = 6 &&

// Purpose: BTN-open SRP SB acts FIRST into BB+BTN.

f$cc_flop_donk_6max_btnopen_context &&
f$cc_hero_pos_id = 6 &&

// Purpose: count mutually exclusive adapted BTN+blinds policy parents.
// Source/Provenance: P safety invariant over T/A exact contexts.
##f$cc_flop_donk_6max_parent_count##
(f$cc_flop_donk_6max_limped_sb_context * 1) +
(f$cc_flop_donk_6max_limped_bb_context * 1) +
(f$cc_flop_donk_6max_btnopen_sb_context * 1) +
(f$cc_flop_donk_6max_btnopen_bb_context * 1)

// Purpose: stable parent ID: 1 limp-SB; 2 limp-BB; 3 BTNopen-SB; 4 BTNopen-BB.
// Source/Provenance: P routing metadata.
##f$cc_flop_donk_6max_parent_id##

When f$cc_flop_donk_6max_btnopen_sb_context Return 3 Force

When Others Return 0 Force

// -----------------------------------------------------------------------------
// FD6.02 — adapted hand / board selectors
// -----------------------------------------------------------------------------

// Purpose: robust value region that can support a selected three-way Donk without
// treating one-pair as commitment.

// Provenance: A/P over T contribution-aware hand strength.

f$cc_hand_two_pair_or_better

// Source/Provenance: A source TP+ ingredient; P policy downstream.
##f$cc_flop_donk_6max_overpair##
f$cc_cbet_flop_overpair && !f$cc_hand_two_pair_or_better

// Purpose: source-descended low pair <=7, generalized outside native 3h context.
// Source: dedicated `7 or lower pair` rule.
// Provenance: A mechanical contribution reconstruction + P use only in selected
// limped-BB states; it is NOT copied into BTN-open SRP.

When !ispair && RankOfFirstHoleCard <= 7 && (RankOfFirstHoleCard = FirstFlopCard || RankOfFirstHoleCard = SecondFlopCard || RankOfFirstHoleCard = ThirdFlopCard) Return true Force
When !ispair && RankOfSecondHoleCard <= 7 && (RankOfSecondHoleCard = FirstFlopCard || RankOfSecondHoleCard = SecondFlopCard || RankOfSecondHoleCard = ThirdFlopCard) Return true Force
When Others Return false Force

// Purpose: boards where the source preferred checking draws and where 4-6h
// adaptation also avoids manufacturing a lead: A-high, completed, or 2+BW.

f$cc_flop_donk_source_two_plus_bw

// Source: source leads more on 1BW/NoBW/paired boards.
// Provenance: A source principle + P six-max pressure abstraction.

f$cc_flop_static_lowmid_parent ||
f$cc_flop_dynamic_lowmid_parent ||
(f$cc_flop_paired_parent && !f$cc_flop_ahigh)

// Donks; static high boards remain mostly check-to-PFA.
// Source/Provenance: P professional range-interaction abstraction constrained by A.

!f$cc_flop_ahigh &&
(f$cc_flop_dynamic_lowmid_parent ||
 (f$cc_flop_paired_parent && f$cc_flop_donk_source_broadway_count <= 1))

// Purpose: source-descended low-SPR POT-sizing candidate using corrected deepest
// effective relation; no action follows from this descriptor by itself.
