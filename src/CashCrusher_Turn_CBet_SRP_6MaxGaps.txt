// ============================================================================
// Scope:
//   Six-max ordinary SRP matchups that do not have a literal Spin range parent:
//   * UTG/HJ/CO PFA IP versus SB or BB;
//   * UTG/HJ/CO PFA OOP versus a later nonblind cold caller.
//
// Source boundary:
//   DeepCrusher/Starting Strategy contributes A-level structure: current-strength
//   reclassification, selective later-street pressure after a flop call, IP/OOP
//   separation, runout sensitivity and protection of checking ranges.
//
// Provenance:
//   P-heavy. Exact range interaction/frequencies below are deterministic
//   professional-theory baselines for six-max cash. They are NOT claimed as
//   solver-exact and they are deliberately narrower than copying BTN/HU tails.
//
// Professional-theory principles used:
//   * early/middle opener range remains strong but blind/coldcall range narrows
//     materially after calling flop;
//   * BB continues wider than SB, allowing somewhat more thin/semi-bluff pressure;
//   * later-position nonblind coldcallers realize equity well IP, so OOP PFA checks
//     more medium value/draws;
//   * new straight/flush and four-card runouts reduce automatic one-pair barrels;
//   * strong made value and high-equity semibluffs remain active;
//   * pure-air barrels require a credible range-advantage turn and good flop plan;
//   * betting one pair never grants stack-off permission.
// ============================================================================

// Source/Provenance: P six-max range family; SB continue is treated more selected

// Purpose: dangerous turn for medium made value: newly completed or four-card
// straight/flush public topology.
// Source: A source repeatedly treats completed/four-card runouts cautiously.
// Provenance: A/P generalized cash danger parent.
##f$cc_turn_srp_gap_dangerous_runout##
f$cc_turn_new_completion || f$cc_turn_four_card_straight_or_flush || f$cc_turn_super_completed

// Purpose: favorable high-card pressure turn for an earlier PFA range.
// Source/Provenance: P range-advantage selector; exact matchup still required.
##f$cc_turn_srp_gap_high_pressure_turn##
!f$cc_turn_new_completion &&
!f$cc_turn_pairs_flop_rank &&
f$cc_turn_overcard_to_flop &&
(f$cc_turn_is_ace || f$cc_turn_is_king)

// Purpose: P-heavy Turn CBet baseline for UTG/HJ/CO opener IP versus BB.
// Source: no literal DeepCrusher range branch exists for these six-max matchups;
// DeepCrusher supplies only current-strength/runout/second-barrel architecture.

// Professional fill: BB is the widest blind continue family. Robust value keeps
// betting; one-pair checks increase on completion/four-card runouts; high-equity
// no-made draws can barrel; pure air is limited to A/K pressure turns from a
// quality-air flop plan.

// made classes remain in value branch. No jam is encoded.

When f$cc_turn_cbet_overpair Return true Force

When f$cc_turn_cbet_strong_top_pair Return true Force
When f$cc_turn_cbet_medium_top_pair && user_cc_flop_cbet_texture_static_high && !f$cc_turn_srp_gap_dangerous_runout Return true Force
When f$cc_turn_cbet_medium_top_pair && f$cc_pair_plus_draw && !f$cc_turn_super_completed Return true Force
When f$cc_turn_cbet_medium_top_pair Return false Force
When f$cc_turn_cbet_weak_top_pair Return false Force
When f$cc_turn_cbet_second_pair Return false Force
When f$cc_turn_cbet_third_or_worse_pair Return false Force
When f$cc_hand_no_made && f$cc_turn_cbet_premium_draw && !f$cc_turn_super_completed Return true Force
When f$cc_hand_no_made && f$cc_turn_cbet_good_draw && f$cc_turn_srp_gap_high_pressure_turn Return true Force
When f$cc_hand_no_made && f$cc_real_frontdoor_draw Return false Force
When f$cc_turn_cbet_air && user_cc_flop_cbet_had_quality_air && f$cc_turn_srp_gap_high_pressure_turn Return true Force
