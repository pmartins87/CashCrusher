When f$cc_cbet_flop_strong_top_pair Return true Force

When f$cc_cbet_flop_medium_top_pair && f$cc_flop_static_high_parent && !f$cc_mw_srp_true3_two_nonblinds Return true Force

When f$cc_cbet_flop_weak_top_pair Return false Force

When f$cc_cbet_flop_good_draw && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
