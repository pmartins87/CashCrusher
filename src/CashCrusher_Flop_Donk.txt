// Purpose: compact reviewed Flop-Donk family ID.
// IDs: 1 native source; 2 4-6h BTN+both-blinds adaptation; 0 unsupported.
// Source/Provenance: P routing metadata over A/T/P reviewed coverage.

// Purpose: canonical Flop Donk action router.
// Source/Provenance: A/P source-first exact-family router; unknown ->check.

When f$cc_flop_donk_6max_covered Return f$cc_flop_donk_6max_action Force

// Source/Provenance: A/P exact owner; check/uncovered ->0.

When f$cc_flop_donk_source_covered Return f$cc_flop_donk_source_size_id Force
When f$cc_flop_donk_6max_covered Return f$cc_flop_donk_6max_size_id Force

// Purpose: current Flop Donk state has a reviewed policy, including explicit check.
// Source/Provenance: P coverage contract over source + adapted families.
##f$cc_flop_donk_strategy_covered##

// Purpose: action/size integrity.
// Source/Provenance: P safety invariant.
##f$cc_flop_donk_size_consistent##

When f$cc_flop_donk_router Return f$cc_flop_donk_size_id >= 1 && f$cc_flop_donk_size_id <= 3 Force
When Others Return false Force
