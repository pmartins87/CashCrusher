// Purpose:
//   Convert a reviewed River-Float size to BetMax ONLY when that requested size
//   already reaches Hero's balance or every live effective relationship.
//
// Source boundary:
//   DeepCrusher RiverMax and historical ~50/55/60 promotion mechanisms are not
//   one global cash River-Float rule. They remain diagnostics. Exact strategic
//   jams, if later justified, stay node-owned.
//
// Source/Provenance:
//   T = OpenHoldem BetMax/balance/effective-stack execution geometry.
//   A = mechanical equivalence contract frozen on prior attack families.
//   P = multiway sidepot safety and pre-action same-River defense provenance.
//
// Safety:
//   * no hand class creates BetMax by itself;
//   * shortest-only MW reach never promotes;
//   * plan markers are intent, not proof of executed action;
//   * any later River raise belongs to defense and current round-4 history.
// ============================================================================

// Purpose: requested River Float reaches every currently matchable live relation.
// Source/Provenance: T/A HU exact / MW deepest whole-field reach definition.
##f$cc_river_float_requested_reaches_all_live_effective##
When !f$cc_river_float_stackgeom_clean Return false Force
When f$cc_hu && f$cc_river_float_requested_reaches_hu_effective Return true Force
When f$cc_multiway && f$cc_river_float_requested_reaches_mw_deepest Return true Force
When Others Return false Force

// Purpose: local natural all-in equivalence for initial River Float.
// Source/Provenance: T/A mechanical equivalence, not strategic commitment.
// Safety: historical 50/60 diagnostics and shortest-only sidepot reach excluded.
##f$cc_river_float_natural_allin_equivalent##
When !f$cc_river_float_runtime_size_ready Return false Force
When !f$cc_river_float_stackgeom_clean Return false Force
When f$cc_river_float_requested_reaches_hero_stack Return true Force
When f$cc_river_float_requested_reaches_all_live_effective Return true Force
When Others Return false Force

// Purpose: reason why natural all-in equivalence fired.
// IDs: 1 Hero stack; 2 HU effective; 3 MW deepest/all-live; 0 none.
// Source/Provenance: P metadata over T/A mechanical conditions.
##f$cc_river_float_natural_allin_reason_id##
When !f$cc_river_float_natural_allin_equivalent Return 0 Force
When f$cc_river_float_requested_reaches_hero_stack Return 1 Force
When f$cc_hu && f$cc_river_float_requested_reaches_hu_effective Return 2 Force
When f$cc_multiway && f$cc_river_float_requested_reaches_mw_deepest Return 3 Force
When Others Return 0 Force

// Purpose: final River-Float execution betsize plus same-River plan provenance.
// Source/Provenance: T OpenPPL BetMax/requested action + A/P pre-action markers.
// Safety: markers never prove execution; later defense must inspect round4 actions.
##f$cc_river_float_execution_betsize##
When !f$cc_river_float_runtime_size_ready Return 0 Force
When f$cc_river_float_runtime_size_ready Set user_cc_river_float_opportunity_seen
When f$cc_river_float_runtime_size_ready Set user_cc_river_float_plan_bet_seen
When f$cc_river_float_runtime_size_ready Set user_cc_river_float_plan_size_recorded
When f$cc_river_float_size_id = 1 Set user_cc_river_float_plan_size_25
When f$cc_river_float_size_id = 2 Set user_cc_river_float_plan_size_33
When f$cc_river_float_size_id = 3 Set user_cc_river_float_plan_size_50
When f$cc_river_float_size_id = 4 Set user_cc_river_float_plan_size_75
When f$cc_river_float_size_id = 5 Set user_cc_river_float_plan_size_100
When f$cc_river_float_natural_allin_equivalent Set user_cc_river_float_plan_expected_allin
When f$cc_river_float_natural_allin_equivalent Return BetMax Force
When Others Return f$cc_river_float_requested_betsize Force

// Purpose: count mutually exclusive stored River-Float plan-size markers.
// Source/Provenance: P integrity over T per-hand user-variable semantics.
##f$cc_river_float_plan_size_marker_count##
(user_cc_river_float_plan_size_25 * 1) +
(user_cc_river_float_plan_size_33 * 1) +
(user_cc_river_float_plan_size_50 * 1) +
(user_cc_river_float_plan_size_75 * 1) +
(user_cc_river_float_plan_size_100 * 1)

// Purpose: validate stored River-Float pre-action plan markers.
// Source/Provenance: P engineering invariant over T user-variable semantics.
##f$cc_river_float_plan_markers_consistent##
When user_cc_river_float_plan_size_recorded && !user_cc_river_float_plan_bet_seen Return false Force
When user_cc_river_float_plan_bet_seen && !user_cc_river_float_plan_size_recorded Return false Force
When user_cc_river_float_plan_size_recorded && f$cc_river_float_plan_size_marker_count != 1 Return false Force
When !user_cc_river_float_plan_size_recorded && f$cc_river_float_plan_size_marker_count != 0 Return false Force
When user_cc_river_float_plan_expected_allin && !user_cc_river_float_plan_size_recorded Return false Force
When Others Return true Force

// Purpose: prove shortest-only sidepot reach cannot trigger local BetMax while a
// deeper live opponent remains uncovered.
// Source/Provenance: P invariant over T dual-bound geometry.
##f$cc_river_float_sidepot_divergence_not_promoted##
When !f$cc_river_float_mw_sidepot_divergence_candidate Return true Force
When f$cc_river_float_natural_allin_equivalent Return false Force
When Others Return true Force
