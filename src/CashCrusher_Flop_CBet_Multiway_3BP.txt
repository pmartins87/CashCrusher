// -----------------------------------------------------------------------------
// M3P.01 — EXACT THREE-WAY PLAIN 3BP
// -----------------------------------------------------------------------------

// Purpose: choose CBet/check in exact-threeway plain 3BP.
// Context: Hero final 3bettor versus two ranges that are opener/post-3bet-caller
// origins only; no pre-3bet caller is legal in plain subtype.
// Provenance: P-heavy; A source supplies generic 3BP/CBet principles only.
// Decision logic: strong value and static overpairs/TP remain active; marginal
// one-pair tightens; premium draws selective; air only narrow LAST/static-high
// best-backdoor case when original opener is still present.
##f$cc_cbet_mw_plain3bp_exact3_action##
When !f$cc_mw_plain3bp_exact3_context Return false Force
When !f$cc_mw_3bp_context_consistent Return false Force
When f$cc_cbet_flop_very_strong_value Return true Force
When f$cc_cbet_flop_overpair && f$cc_flop_dynamic_lowmid_parent && !f$cc_mw_all_effective_spr_below_3 Return false Force
When f$cc_cbet_flop_overpair && (f$cc_flop_static_high_parent || f$cc_flop_static_lowmid_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_overpair && f$cc_flop_dynamic_high_parent && !f$cc_mw_3bp_all_live_are_coldcallers Return true Force
When f$cc_cbet_flop_overpair && f$cc_flop_dynamic_lowmid_parent && f$cc_mw_3bp_last_context && f$cc_mw_all_effective_spr_below_3 Return true Force
When f$cc_cbet_flop_overpair Return false Force
When f$cc_cbet_flop_strong_top_pair && f$cc_pair_plus_draw Return true Force
When f$cc_cbet_flop_strong_top_pair && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_strong_top_pair && f$cc_flop_dynamic_lowmid_parent && f$cc_mw_3bp_last_context && f$cc_mw_all_effective_spr_below_3 Return true Force
When f$cc_cbet_flop_strong_top_pair Return false Force
When f$cc_cbet_flop_medium_top_pair && f$cc_flop_static_high_parent && f$cc_mw_3bp_last_context && f$cc_mw_3bp_has_live_opener && f$cc_mw_all_effective_spr_below_4 Return true Force
When f$cc_cbet_flop_medium_top_pair Return false Force
When f$cc_cbet_flop_weak_top_pair Return false Force
When f$cc_cbet_flop_showdown_pair Return false Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_3bp_last_context Return true Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_3bp_middle_context && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_3bp_first_context && f$cc_flop_static_high_parent && !f$cc_mw_3bp_all_live_are_coldcallers Return true Force
When f$cc_real_frontdoor_draw Return false Force
When f$cc_cbet_flop_air_best_backdoors && f$cc_flop_static_high_parent && f$cc_mw_3bp_last_context && f$cc_mw_3bp_has_live_opener && !f$cc_mw_3bp_all_live_are_coldcallers Return true Force
When Others Return false Force

// Purpose: size positive exact-threeway plain-3BP CBet.
// Source/Provenance: P 3BP multiway sizing, A texture-sensitive ancestry.
##f$cc_cbet_mw_plain3bp_exact3_size_id##
When !f$cc_cbet_mw_plain3bp_exact3_action Return 0 Force
When f$cc_flop_dynamic_lowmid_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_premium_draw) Return 3 Force
When f$cc_flop_dynamic_lowmid_parent Return 2 Force
When f$cc_flop_dynamic_high_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_overpair || f$cc_cbet_flop_premium_draw) Return 2 Force
When f$cc_flop_dynamic_high_parent Return 1 Force
When f$cc_flop_static_lowmid_parent && f$cc_cbet_flop_very_strong_value Return 2 Force
When f$cc_flop_static_high_parent || f$cc_flop_static_lowmid_parent || f$cc_flop_paired_parent Return 1 Force
When Others Return 2 Force
