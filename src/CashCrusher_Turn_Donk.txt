// Purpose: compact reviewed Turn-Donk family ID.
// IDs: 1=native `(BBorSB)v2pp`; 2=HUBB/BvB; 0=uncovered.
// Source/Provenance: P routing metadata over separately audited descendants.
##f$cc_turn_donk_family_id##

When f$cc_turn_donk_source_native_covered Return 1 Force
When f$cc_turn_donk_hubb_covered Return 2 Force
When Others Return 0 Force

// Purpose: canonical Turn Donk action router.
// Source/Provenance: A/P exact audited child only; unknown ->check.
##f$cc_turn_donk_router##
When !f$cc_turn_donk_opportunity Return false Force
When f$cc_turn_donk_source_native_covered Return f$cc_turn_donk_source_native_action Force
When f$cc_turn_donk_hubb_covered Return f$cc_turn_donk_hubb_action Force
When Others Return false Force

// Purpose: paired strategic size router.
// Source/Provenance: A/P exact owner; checks/uncovered ->0.
##f$cc_turn_donk_size_id##

When f$cc_turn_donk_source_native_covered Return f$cc_turn_donk_source_native_size_id Force
When f$cc_turn_donk_hubb_covered Return f$cc_turn_donk_hubb_size_id Force
When Others Return 0 Force

// Source/Provenance: P coverage contract.
##f$cc_turn_donk_strategy_covered##

// Purpose: action/size integrity, including source-approved BetMin ID 5.
// Source/Provenance: P safety invariant.
##f$cc_turn_donk_size_consistent##

When f$cc_turn_donk_router Return f$cc_turn_donk_size_id >= 1 && f$cc_turn_donk_size_id <= 5 Force
When Others Return false Force

// Purpose: visible Turn Donk opportunity not yet reviewed or lacking necessary
