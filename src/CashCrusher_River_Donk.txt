// Purpose:
//   Route only River-lead states whose closed history and strategy family have
//   been audited. A generic OOP/no-initiative router is never positive strategy.
//
// Current family:
//   1 = literal true-HU HUBB flop-X/C -> turn-X/C source parent.
//
// Deliberately unowned for now:
//   * 3-6h reduced-HU descendants;
//   * flop/turn multiway histories;
//   * ISO, 3BP, squeeze, 4BP and 5BP+ gaps;
//   * source HUBB branches needing defense-written Turn provenance.
//
// Source/Provenance:
//   T/A = Gate09A exact history + Gate09B source branch.
//   P = fail-closed ownership/exclusivity only.
// ============================================================================

// Purpose: compact current River-Donk family ID.
// Source/Provenance: P router over audited children only.
##f$cc_river_donk_family_id##
When !f$cc_river_donk_base_opportunity Return 0 Force
When f$cc_river_donk_hubb_covered Return 1 Force
When Others Return 0 Force

// Purpose: canonical River Donk action.
// Source/Provenance: T/A source child; all other states check/fail closed.
##f$cc_river_donk_router##
When !f$cc_river_donk_base_opportunity Return false Force
When f$cc_river_donk_hubb_covered Return f$cc_river_donk_hubb_action Force
When Others Return false Force

// Purpose: canonical local strategic size ID.
// IDs: 1=25 2=30 3=33 4=50 5=75 6=100.
// Source/Provenance: T/A exact child size.
##f$cc_river_donk_size_id##
When !f$cc_river_donk_base_opportunity Return 0 Force
When f$cc_river_donk_hubb_covered Return f$cc_river_donk_hubb_size_id Force
When Others Return 0 Force

// Purpose: current River Donk state has an audited strategic owner.
// Source/Provenance: P coverage union.
##f$cc_river_donk_strategy_covered##
f$cc_river_donk_hubb_covered

// Purpose: current source-phase owner count.
// Source/Provenance: P exclusivity invariant.
##f$cc_river_donk_reviewed_family_count##
f$cc_river_donk_hubb_covered * 1

// Purpose: audited River Donk states have exactly one owner; unowned have zero.
// Source/Provenance: P fail-closed safety.
##f$cc_river_donk_family_exclusive##
When !f$cc_river_donk_strategy_covered Return f$cc_river_donk_reviewed_family_count = 0 Force
When Others Return f$cc_river_donk_reviewed_family_count = 1 Force

// Purpose: positive River Donk action must own one positive local size.
// Source/Provenance: P action/size integrity.
##f$cc_river_donk_size_consistent##
When !f$cc_river_donk_family_exclusive Return false Force
When !f$cc_river_donk_router Return f$cc_river_donk_size_id = 0 Force
When f$cc_river_donk_router Return f$cc_river_donk_size_id >= 1 && f$cc_river_donk_size_id <= 6 Force
When Others Return false Force

// Purpose: visible River-Donk opportunity not yet owned by an audited child.
// Source/Provenance: P development diagnostic.
##f$cc_river_donk_uncovered_context##
f$cc_river_donk_base_opportunity && !f$cc_river_donk_strategy_covered
