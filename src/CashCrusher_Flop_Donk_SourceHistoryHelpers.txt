//   Preserve direct `(BBorSB)v2pp` flop CHECK sub-states that are strategically
//   relevant one street later. Gate07's action router deliberately treated many
//   source-reviewed checks alike; Turn Donk needs to know which kind of check it
//   actually was before any source descendant may fire.
//
// Source:
//   Dedicated Starting Strategy `(BBorSB)v2pp`:
//     * good/medium draws on Ax/CPL/2+BW prefer X/C;
//     * A-high + BDSD, or lower high-card + BDFD + OC, may X/C only versus a
//       very small (~33%) flop bet and can later donk after a 2HC draw pickup.
//   Mature DeepCrusher uses the same A-high/BDSD and lower-high/BDFD+OC split.
//
// Provenance:
//   T/A = direct source categories assembled from existing CashCrusher flop
//         hand/backdoor primitives.
//   P   = helper naming / history-only separation.
//
// Safety:
//   These are pre-action descriptors only. They NEVER prove Hero actually called
//   a flop bet, never authorize the flop call price, and never select Turn action
//   by themselves. Closed `did*round2` history remains mandatory downstream.
// ============================================================================

When Others Return false Force
