// ============================================================================
// CashCrusher_Flop_CBet.txt
// Gate 01 — six-max cash flop CBet routing contract
// ============================================================================
// Purpose:
//   Separate pot/range families BEFORE any strategic CBet policy is allowed to
//   fire.  A good strategy routed to the wrong range topology is still a bug.
//
// CashCrusher terminology:
//   CBet = Hero was the final preflop aggressor in a raised pot and faces no flop
//   bet before acting.  Unraised/limped-pot bets are owned by different nodes,
//   except the separately proven true-HU SB-limp -> BB-raise family.
//
// Critical HU distinction:
//   origin=1 TRUE HU DEAL;
//   origin=2 multi-handed deal reduced to HU PRE-FLOP;
//   origin=3 multiway flop reduced to HU POST-FLOP.
// These origins never share a range policy merely because two players remain.
//
// Pot-family separation:
//   ordinary SRP | true-HU limp-raised | ISO | ordinary 3BP | squeeze | 4BP.
//
// Source/Provenance:
//   A = routing architecture adapted from audited DeepCrusher initiative/history;
//   P = six-max topology separation where the Spin source has no literal state;
//   X = unsupported families fail closed rather than borrowing a neighbor.
//
// OpenPPL safety:
//   all WHEN rules are complete.  Indentation is never used to imply logical
//   scope.  Every unsupported child returns false / size 0 explicitly.
// ============================================================================

// -----------------------------------------------------------------------------
// 01.01 — CBet opportunity and top-level family router
// -----------------------------------------------------------------------------

// Purpose: prove that the current decision may legally belong to a flop CBet node.
// Context: flop only, mechanically valid context, no bet to call, Hero is final
// preflop aggressor in a supported raised-pot role.
// Source/Provenance: A from DeepCrusher initiative routing; P generalization to
// PFA/3bettor/4bettor role IDs.
// Safety: opportunity does not imply strategy coverage or a positive bet.
##f$cc_flop_cbet_opportunity##
When !IsFlop Return false Force
When !f$cc_context_valid Return false Force
When AmountToCall > 0 Return false Force
When f$cc_pf_role_id <= 0 Return false Force
When f$cc_pf_role_pfa Return true Force
When f$cc_pf_role_3bettor Return true Force
When f$cc_pf_role_4bettor Return true Force
When Others Return false Force
