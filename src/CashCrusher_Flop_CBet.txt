// This file separates poker families BEFORE strategy is allowed to fire.
// Unreviewed child families fail closed.
//
// CashCrusher terminology:
//   CBet = Hero was final preflop aggressor in a raised pot and is checked to.
//   A bet in an unraised/limped pot is NOT routed here unless a raise created a
//   proven HU limp-raised pot (SB limp -> BB raise -> call).
//
// Critical HU distinction:
//   TRUE HU DEAL (origin=1) != 3-6h deal reduced to HU by preflop folds (origin=2)
//   != a former multiway flop that later becomes HU (origin=3).
//
// Pot family separation:
//   ordinary SRP | HU limp-raised pot | ISO | ordinary 3BP | squeeze | 4BP | 5BP+
//
// Gate 01 current strategic coverage:
//   * TRUE HU ordinary SRP, SB/Button PFA IP vs BB;
//   * TRUE HU SB limp -> BB raise -> call, BB PFA OOP;
//   * reduced-HU ordinary SRP PFA IP vs BB/SB;
//   * reduced-HU ordinary SRP PFA OOP: SB-v-BB and opener-v-later cold caller.
//
// Other pot families remain explicit false stubs until individually audited.
// ============================================================================
