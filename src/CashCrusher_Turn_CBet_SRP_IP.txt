// Purpose: exact New-Crushfest HUSB "good draw" second-barrel family.
// Source: 2HC FD; 2HC OESD+mOC; 2HC GS+OC/2mOC.
// Provenance: A reconstruction using current portable draw/equity symbols.
// Safety: no-made only; this descriptor has no stack-off implication.
##f$cc_turn_husb_source_good_draw##
f$cc_turn_srp_ip_true_hu_context &&
f$cc_hand_no_made &&
((f$cc_real_fd && SuitsInHand = 1) ||
 (f$cc_real_oesd && (nstraightfillcommon - nstraightfill = 2) && f$cc_one_or_more_overcards) ||
 (f$cc_real_gutshot && (nstraightfillcommon - nstraightfill = 2) && f$cc_one_or_more_overcards))

// Purpose: true-HU HUSB second-barrel action.
// Source: New Crushfest HUSB Turn sections plus audited compatible current source.
// Provenance: A for branch direction; A/P for deep-cash deterministic sizing use.
// Decision logic:
//   * current 2P+ remains value-first;
//   * one-pair on super-completed turn checks unless it has premium redraw equity;
//   * carried flop TP demoted by turn OC uses smaller 50 source barrel;
//   * current TP/OP normally value barrels;
//   * 2nd pair 50 nCPL / 25 CPL; 3rd-or-worse pair 25;
//   * source-good draws 75; other no-made draws check;
//   * flop-air barrels only exact source pressure card.
// Safety: any response to a turn raise belongs to defense, not this function.
##f$cc_turn_srp_ip_true_hu_action##
When !f$cc_turn_srp_ip_true_hu_context Return false Force
When f$cc_turn_cbet_two_pair_plus Return true Force
When (f$cc_turn_cbet_overpair || f$cc_turn_cbet_top_pair) && f$cc_turn_super_completed && !f$cc_turn_cbet_premium_draw Return false Force
When f$cc_turn_cbet_flop_tp_demoted && f$cc_turn_overcard_to_flop Return true Force
When f$cc_turn_cbet_overpair Return true Force
When f$cc_turn_cbet_top_pair Return true Force
When f$cc_turn_cbet_second_pair Return true Force
When f$cc_turn_cbet_third_or_worse_pair Return true Force
When f$cc_turn_husb_source_good_draw Return true Force
When f$cc_hand_no_made && f$cc_real_frontdoor_draw Return false Force
When f$cc_turn_cbet_air && (user_cc_flop_cbet_had_quality_air || user_cc_flop_cbet_had_pure_air) && f$cc_turn_husb_air_pressure_card_source Return true Force
When Others Return false Force

// Purpose: paired size router for true-HU HUSB second barrel.
// Source: HUSB 75 TP+/good-draw; flop-TP+OC 50; MP 50/25; 3rd pair 25;
// air pressure source line 75.
// Provenance: A source sizes. Historical optional 100/200 deep Spin rule is not
// generalized by stack depth here.
##f$cc_turn_srp_ip_true_hu_size_id##
When !f$cc_turn_srp_ip_true_hu_action Return 0 Force
When f$cc_turn_cbet_two_pair_plus Return f$cc_turn_size_75_id Force
When f$cc_turn_cbet_flop_tp_demoted && f$cc_turn_overcard_to_flop Return f$cc_turn_size_50_id Force
When (f$cc_turn_cbet_overpair || f$cc_turn_cbet_top_pair) Return f$cc_turn_size_75_id Force
When f$cc_turn_cbet_second_pair && f$cc_turn_completed Return f$cc_turn_size_25_id Force
When f$cc_turn_cbet_second_pair Return f$cc_turn_size_50_id Force
When f$cc_turn_cbet_third_or_worse_pair Return f$cc_turn_size_25_id Force
When f$cc_turn_husb_source_good_draw Return f$cc_turn_size_75_id Force
When f$cc_turn_cbet_air && f$cc_turn_husb_air_pressure_card_source Return f$cc_turn_size_75_id Force
When Others Return 0 Force
