// Purpose: validate closed-turn lastraised3 chair before bit operations.
// Source/Provenance: T OpenHoldem previous-round aggressor history.

// Purpose: prove lastraised3 is independently present in persisted raisbits3.

// Purpose: canonical six-max position ID of actual final turn aggressor.
// Source/Provenance: T chair aliases + A Gate00 2-6h position mapping.
// True-HU safety: dealer=SB maps to position 5, never BTN 4.

When lastraised3 = smallblindchair Return 5 Force
When lastraised3 = bigblindchair Return 6 Force
When Others Return 0 Force

// Purpose: final turn aggressor remains a live opponent on river.
