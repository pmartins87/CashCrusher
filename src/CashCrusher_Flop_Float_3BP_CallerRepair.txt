//   plus `raisbits1`, so Hero no longer needs to have raised for final-aggressor
//   identity.  This file repairs ONLY pure cold-caller descendants. Existing
//   opener-call branches remain owned by Gate04E.
//
// Provenance:
//   T = OpenHoldem final-raiser/current-live history.
//   A = Gate04E hand/size policy copied without strategic expansion.
//   P = caller-stage topology proof and fail-closed chronology repair.

// Source/Provenance: A exact Gate04E policy transplant; chronology only was fixed.
##f$cc_flop_float_rt3bp_plain_postcold_hu_action##

When f$cc_hand_two_pair_or_better Return true Force
When HaveOverPair && !f$cc_hand_two_pair_or_better Return true Force
When f$cc_cbet_flop_strong_top_pair Return true Force
When f$cc_hand_top_pair_or_better Return false Force
When f$cc_hand_middle_or_bottom_pair Return false Force
When f$cc_flop_float_premium_draw Return true Force
When f$cc_flop_float_good_draw && f$cc_flop_float_dry_parent Return true Force
When f$cc_flop_float_air Return false Force
When Others Return false Force

// Purpose: repaired plain post-coldcaller size map.
// Source/Provenance: A exact Gate04E 50/75 map.
