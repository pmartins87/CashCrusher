// Gate 10E — ordinary-SRP OOP caller Turn-Probe six-max gaps
// ============================================================================
// Purpose:
//   Fill ordinary one-raise HU Turn-Probe states that have no literal complete
//   Spin source tree after a CLOSED flop check-through. Direct HUBB/3w source and
//   reviewed SBvBTN TBP descendants always keep precedence.
//
// Exact strategic geometry owned here:
//   * Hero is SB or BB caller, OOP versus the sole preflop opener;
//   * 3-6 players were dealt, flop entered HU, and flop truly checked through;
//   * BTN-open descendants are reviewed separately from CO and UTG/HJ ranges;
//   * native 3wSBvBTN is excluded because Gate10B.2/10C already own that family;
//   * native 3wBBvBTN keeps its explicit high-air source line first, then this
//     module reviews the otherwise source-silent made/draw remainder.
//
// Source hierarchy / provenance:
//   T = exact Gate00 pot/position/history, Gate10 snapshot and current hand facts.
//   A = direct 3wBBvBTN/SBvBTN range-pressure principles only where structurally
//       comparable; literal source actions are NOT widened silently.
//   P = conservative 100bb six-max cash policy for source-silent exact ranges.
//   X = generic TP+ stackoff, broad air probing versus tight openers, shortest-
//       stack commitment and any future River/raise-defense ownership.
//
// Cash-depth principle:
//   A checked-back PFA is capped relative to its betting range, but not empty of
//   strong hands. Earlier-position opening ranges remain materially stronger than
//   BTN ranges. Therefore this gap layer expands value/equity probes far more
//   readily than pure-air probes, and tightens monotonically BTN -> CO -> UTG/HJ.
// ============================================================================

// Source/Provenance: T current hand fact; policy remains local.
##f$cc_turn_probe_srp_overpair##

// Purpose: strong exact TP, using the already-audited CashCrusher kicker ladder.
// Source: DeepCrusher repeatedly splits TP by kicker.
// Provenance: A source concept + P <=2 better-kicker engineering boundary.
##f$cc_turn_probe_srp_strong_tp##

// Source/Provenance: A/P deterministic quality split.
##f$cc_turn_probe_srp_medium_tp##

// Source/Provenance: A/P deterministic residue.
##f$cc_turn_probe_srp_weak_tp##

// Purpose: premium no-made Turn draw, without stack-off semantics.
// Source: DeepCrusher good/combo/nut draw ingredients.
// Provenance: A/P same cleaned quality concept used by other CashCrusher nodes.
##f$cc_turn_probe_srp_premium_draw##
IsTurn && f$cc_hand_no_made &&
(f$cc_real_combo_draw || f$cc_real_nut_fd ||
 (f$cc_real_oesd && f$cc_two_overcards) ||
 (f$cc_real_fd && f$cc_two_overcards))

// Purpose: useful no-made draw below premium tier.
// Source/Provenance: A/P conservative semibluff quality split.
##f$cc_turn_probe_srp_good_draw##

!f$cc_turn_probe_srp_premium_draw &&
(f$cc_real_fd || f$cc_real_oesd || (f$cc_real_gutshot && f$cc_two_overcards))

// Purpose: four-card board contains an Ace.
// Source: source/TBP bad-bluff ingredient.
// Provenance: T/A reconstruction from saved flop + current Turn.

// Purpose: four-card board contains at least two broadway cards.
// Source/Provenance: T/A Gate10 saved flop broadway count + current Turn card.

(user_cc_turn_probe_flop_had_1bw && f$cc_turn_is_broadway)

// Source/Provenance: P complement inside this exact gap family.
##f$cc_turn_probe_srp_favorable_turn##
