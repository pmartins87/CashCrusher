// Purpose: clean enough 4BP River for one-pair value.

// -----------------------------------------------------------------------------
// R4.01 — OPENER4 versus original 3BETTOR
// -----------------------------------------------------------------------------

// Purpose: clean true/reduced opener4-v-3bettor River action.
// Source: no literal source 4BP tree.
// Provenance: P professional low-SPR 4BP fill.
// Logic: robust value broad; OP/strong TP can value at natural low SPR or clean
// runouts. Medium TP only at very low SPR IP; no pure-air baseline yet.
##f$cc_river_4bp_opener4_action##
When !f$cc_river_4bp_context_consistent Return false Force
When !(f$cc_river_4bp_truehu_opener4_vs_threebettor || f$cc_river_4bp_opener4_vs_threebettor) Return false Force
When f$cc_river_straight_or_better Return true Force
When f$cc_river_two_pair_plus && !f$cc_river_super_completed Return true Force
When f$cc_river_two_pair_plus && f$cc_river_hu_spr_below_1 Return true Force
When f$cc_river_overpair && f$cc_river_4bp_clean Return true Force
When f$cc_river_overpair && f$cc_river_hu_spr_below_1 Return true Force
When f$cc_river_overpair Return false Force
When f$cc_river_strong_top_pair && f$cc_river_4bp_clean && f$cc_river_hu_spr_below_2 Return true Force
When f$cc_river_strong_top_pair && f$cc_river_hu_spr_below_1 Return true Force
When f$cc_river_medium_top_pair && f$cc_hu_ip && f$cc_river_4bp_clean && f$cc_river_hu_spr_below_1 Return true Force
When f$cc_river_top_pair Return false Force
When f$cc_river_second_pair Return false Force
When f$cc_river_no_made Return false Force
When Others Return false Force

// Source/Provenance: P lower-SPR 50/75/100 map. A 100% request is pot, not BetMax;
// later natural-all-in execution may convert when it actually reaches the stack.

When f$cc_river_straight_or_better || f$cc_river_two_pair_plus Return f$cc_river_size_75_id Force
When f$cc_river_overpair && f$cc_river_hu_spr_below_1 Return f$cc_river_size_75_id Force
When f$cc_river_overpair Return f$cc_river_size_50_id Force
When f$cc_river_top_pair Return f$cc_river_size_50_id Force
When Others Return 0 Force
