// Gate 01I.1 — clean HU four-bet-pot flop CBet
// ============================================================================
// Implemented clean families:
//   1) TRUE HU: SB/Button opener4 IP vs BB 3bettor-call.
//   2) Reduced HU: opener4 vs 3bettor-call, IP/OOP.
//   3) Reduced HU: cold4 vs original opener-call, IP/OOP.
//   4) Reduced HU: cold4 vs original 3bettor-call, IP/OOP.
//
// Not implemented:
//   * non-raiser survivor in 4BP;
//   * limp-reraise/reversed/backraise chronology;
//   * multiway 4BP;
//   * 5bet+;
//   * response to flop raise / later stack-off.
//
// Source boundary:
//   DeepCrusher has no dedicated deep-stack 4BP CBet tree. Initiative, hand,
//   board and IP/OOP architecture is A; exact cash 4BP frequencies are P.
//
// Stack-depth principle:
//   Starting 100bb does not imply high SPR after a 4bet. Low SPR may make some
//   aggressive source ideas valid again, but this CBet node does not pre-decide
//   later commitment. No commitment helper is globally enabled or disabled here.
//
// OpenPPL safety: flat complete WHENs; exact clean subtype/survivor required.
// Size IDs: 1 ~33% | 2 ~50% | 3 ~75% | 0 check
// ============================================================================

// -----------------------------------------------------------------------------
// 4C.01 — TRUE HU opener4 IP vs BB 3bettor-call
// -----------------------------------------------------------------------------

// Purpose: choose flop CBet/check in clean true-HU 4BP with Hero SB/Button IP.
// Source: HUSB contributes IP/texture/hand architecture only; no dedicated 4BP
// frequency exists in DeepCrusher.
// Provenance: A architecture + P compressed-range/low-SPR 4BP theory.
// Decision logic: broad small pressure on static high/paired; robust one-pair
// remains valuable; low connected boards check more; premium draws stay active;
// selected quality air is limited to favorable static parents.
// Safety/Limits: betting TP/overpair here is a flop value decision, not an
// automatic permission to call a future shove or stack off.
##f$cc_cbet_true_hu_4bp_opener4_ip_action##
When !f$cc_cbet_true_hu_4bp_opener4_ip_context Return false Force
When f$cc_cbet_flop_very_strong_value Return true Force
When f$cc_cbet_flop_overpair Return true Force
When f$cc_cbet_flop_strong_top_pair Return true Force
When f$cc_cbet_flop_medium_top_pair && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_medium_top_pair && f$cc_flop_dynamic_high_parent && f$cc_spr_round_start < 3 Return true Force
When f$cc_cbet_flop_medium_top_pair Return false Force
When f$cc_cbet_flop_weak_top_pair && f$cc_flop_static_high_parent && f$cc_spr_round_start < 2 Return true Force
When f$cc_cbet_flop_weak_top_pair Return false Force
When f$cc_hand_second_pair_or_pocket && f$cc_pair_plus_draw Return true Force
When f$cc_hand_second_pair_or_pocket && f$cc_cbet_board_small_bet_parent && f$cc_spr_round_start < 2 Return true Force
When f$cc_cbet_flop_showdown_pair Return false Force
When f$cc_cbet_flop_premium_draw Return true Force
When f$cc_cbet_flop_good_draw && !f$cc_flop_dynamic_lowmid_parent Return true Force
When f$cc_cbet_flop_good_draw && f$cc_flop_dynamic_lowmid_parent && f$cc_two_overcards && f$cc_spr_round_start < 3 Return true Force
When f$cc_real_frontdoor_draw Return false Force
When f$cc_cbet_flop_quality_air && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_air_best_backdoors && f$cc_flop_dynamic_high_parent && f$cc_spr_round_start < 3 Return true Force
When Others Return false Force

// Purpose: size positive true-HU 4BP CBet.
// Source/Provenance: P 4BP sizing constrained by A dry-small/dynamic-larger idea.
// Decision logic: static/paired mostly 33; dynamic robust region 50; 75 is not a
// default because the pot is already large and final stack conversion is Gate01K.
##f$cc_cbet_true_hu_4bp_opener4_ip_size_id##
When !f$cc_cbet_true_hu_4bp_opener4_ip_action Return 0 Force
When f$cc_flop_dynamic_lowmid_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_premium_draw) Return 2 Force
When f$cc_flop_dynamic_lowmid_parent Return 1 Force
When f$cc_flop_dynamic_high_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_overpair || f$cc_cbet_flop_premium_draw) Return 2 Force
When f$cc_flop_dynamic_high_parent Return 1 Force
When f$cc_flop_static_lowmid_parent && f$cc_cbet_flop_very_strong_value Return 2 Force
When f$cc_flop_static_high_parent || f$cc_flop_static_lowmid_parent || f$cc_flop_paired_parent Return 1 Force
When Others Return 1 Force
