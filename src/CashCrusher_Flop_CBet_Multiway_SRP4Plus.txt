// -----------------------------------------------------------------------------
// MW4.01 — EXACT FOUR-WAY
// -----------------------------------------------------------------------------

// Purpose: choose CBet/check on an exact four-player ordinary-SRP flop.
// Context: Hero PFA; three opponents; FIRST/MIDDLE/LAST retained in predicates.
// Source: no direct DeepCrusher four-way source.
// Provenance: P-heavy; A source contributes multiway selectivity and texture logic.
// Decision logic: robust value broad; overpair/strong TP bet static structures;
// marginal one-pair mostly checks; premium draws selective; no pure-air baseline.
##f$cc_cbet_mw_srp_exact4_action##
When !f$cc_mw_srp_exact4_pfa_context Return false Force
When !f$cc_mw_srp_4plus_context_consistent Return false Force
When f$cc_cbet_flop_very_strong_value Return true Force
When f$cc_cbet_flop_overpair && f$cc_flop_dynamic_lowmid_parent Return false Force
When f$cc_cbet_flop_overpair && (f$cc_flop_static_high_parent || f$cc_flop_static_lowmid_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_overpair && f$cc_flop_dynamic_high_parent && f$cc_mw_srp_4plus_pfa_last_context && !f$cc_mw_srp_4plus_nonblind_dense Return true Force
When f$cc_cbet_flop_overpair Return false Force
When f$cc_cbet_flop_strong_top_pair && f$cc_pair_plus_draw Return true Force
When f$cc_cbet_flop_strong_top_pair && f$cc_flop_static_high_parent Return true Force
When f$cc_cbet_flop_strong_top_pair && f$cc_flop_paired_parent && !f$cc_cbet_high_spr Return true Force
When f$cc_cbet_flop_strong_top_pair && f$cc_flop_static_lowmid_parent && f$cc_mw_srp_4plus_pfa_last_context && f$cc_mw_srp_4plus_both_blinds_live Return true Force
When f$cc_cbet_flop_strong_top_pair Return false Force
When f$cc_cbet_flop_medium_top_pair && f$cc_flop_static_high_parent && f$cc_mw_srp_4plus_pfa_last_context && f$cc_mw_srp_4plus_both_blinds_live && f$cc_spr_round_start < 4 Return true Force
When f$cc_cbet_flop_medium_top_pair Return false Force
When f$cc_cbet_flop_weak_top_pair Return false Force
When f$cc_cbet_flop_showdown_pair Return false Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_srp_4plus_pfa_last_context && !f$cc_flop_dynamic_lowmid_parent Return true Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_srp_4plus_pfa_middle_context && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_srp_4plus_pfa_first_context && f$cc_flop_paired_parent Return true Force
When f$cc_real_frontdoor_draw Return false Force
When Others Return false Force

// Purpose: size positive exact-fourway SRP CBet.
// Source/Provenance: P baseline using A texture-sensitive sizing principles.
##f$cc_cbet_mw_srp_exact4_size_id##
When !f$cc_cbet_mw_srp_exact4_action Return 0 Force
When f$cc_flop_dynamic_lowmid_parent && f$cc_cbet_flop_very_strong_value Return 3 Force
When f$cc_flop_dynamic_high_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_premium_draw) Return 2 Force
When f$cc_flop_dynamic_high_parent Return 1 Force
When f$cc_flop_static_lowmid_parent && f$cc_cbet_flop_very_strong_value Return 2 Force
When f$cc_flop_static_high_parent || f$cc_flop_static_lowmid_parent || f$cc_flop_paired_parent Return 1 Force
When Others Return 2 Force

When f$cc_cbet_flop_strong_top_pair && f$cc_pair_plus_draw Return true Force
When f$cc_cbet_flop_strong_top_pair && f$cc_flop_static_high_parent && f$cc_mw_srp_4plus_pfa_last_context Return true Force
When f$cc_cbet_flop_strong_top_pair && f$cc_flop_static_high_parent && f$cc_mw_srp_4plus_pfa_first_context && f$cc_spr_round_start < 4 Return true Force
When f$cc_cbet_flop_strong_top_pair Return false Force
When f$cc_cbet_flop_medium_top_pair Return false Force
When f$cc_cbet_flop_weak_top_pair Return false Force
When f$cc_cbet_flop_showdown_pair Return false Force
When f$cc_cbet_flop_premium_draw && f$cc_mw_srp_4plus_pfa_last_context && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
