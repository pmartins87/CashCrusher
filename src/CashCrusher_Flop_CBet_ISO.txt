//   3-6 handed deal -> proven one-raise ISO -> preflop folds leave HU flop ->
//   Hero is sole preflop aggressor and faces no flop bet before acting.
//

//   survivor type 1 = original PRE-RAISE LIMPER;
//   survivor type 2 = POST-RAISE COLD CALLER.
// They are never merged into one generic "ISO villain" range.
//
// Source hierarchy:
//   A: DeepCrusher `3wBBvSB` checked-to tree explicitly covers ISO/LP/SRP shape;
//      HUSB / 3wBTNvBB / 3wBTNvSB corroborate board/hand principles.
//   P: exact deep-stack six-max ISO frequencies are a format gap and are filled
//      with professional NLHE range-advantage/position/SPR principles.
//   X: shallow <=16/20BB commitment, StackOffDraws and automatic jam tails.
//
// OpenPPL safety:
//   every WHEN is complete; no branch depends on indentation/open-ended scope.
//   unsupported or unproven survivor types fail closed.
//
// Size IDs:
//   1 = ~33% | 2 = ~50% | 3 = ~75% | 0 = check/no CBet
// ============================================================================

// ISO.C01 — IP isolator versus ORIGINAL LIMPER
// -----------------------------------------------------------------------------

// Purpose: decide whether to CBet IP against the surviving pre-raise limper.
// Context: HU ISO, Hero PFA IP, survivor type=limper.
// Source: A from `3wBBvSB` ISO/LP/SRP checked-to principles plus HUSB/BTN source
// families for static-high small betting and selective dynamic-board pressure.
// Provenance: A for source concepts; P for deep-stack combo-selection thresholds.
// Decision logic: robust value/premium equity bet; marginal SDV checks more as
// SPR/board dynamism rise; quality backdoors supply deterministic bluff subset.
// Safety/Limits: not solver-exact; exact matchup ID remains available for later
// refinement; no shallow commitment or automatic raise-vs-XR plan is implied.
##f$cc_cbet_iso_hu_limper_ip_action##
When !f$cc_cbet_iso_hu_limper_ip_context Return false Force
When f$cc_cbet_flop_very_strong_value Return true Force
When f$cc_cbet_flop_overpair Return true Force
When f$cc_cbet_flop_strong_top_pair Return true Force
When f$cc_cbet_flop_medium_top_pair && f$cc_flop_dynamic_lowmid_parent && f$cc_cbet_high_spr Return false Force
When f$cc_cbet_flop_medium_top_pair Return true Force
When f$cc_cbet_flop_weak_top_pair && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) && !f$cc_cbet_very_high_spr Return true Force
When f$cc_cbet_flop_weak_top_pair && f$cc_flop_static_lowmid_parent && !f$cc_cbet_high_spr Return true Force
When f$cc_cbet_flop_weak_top_pair Return false Force
When f$cc_cbet_flop_showdown_pair && f$cc_pair_plus_draw Return true Force
When f$cc_hand_second_pair_or_pocket && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) && !f$cc_cbet_very_high_spr Return true Force
When f$cc_cbet_flop_showdown_pair Return false Force
When f$cc_cbet_flop_premium_draw Return true Force
When f$cc_cbet_flop_good_draw && !f$cc_flop_dynamic_lowmid_parent Return true Force
When f$cc_cbet_flop_good_draw && f$cc_flop_dynamic_lowmid_parent && f$cc_one_or_more_overcards Return true Force
When f$cc_cbet_flop_weak_draw && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_real_frontdoor_draw Return false Force
When f$cc_cbet_flop_quality_air && (f$cc_flop_static_high_parent || f$cc_flop_paired_parent) Return true Force
When f$cc_cbet_flop_air_best_backdoors && f$cc_flop_dynamic_high_parent Return true Force
When f$cc_cbet_flop_air_two_oc_backdoor && f$cc_flop_static_lowmid_parent && !f$cc_cbet_high_spr Return true Force
When Others Return false Force

// Purpose: select flop size for the IP-isolator-vs-limper betting range.
// Source: A from source dry-small/dynamic-larger pattern.
// Provenance: A/P mapping to CashCrusher 33/50/75 deep-stack palette.
// Decision logic: static high/paired small; dynamic high medium; caller-favouring
// dynamic low becomes large only for robust value/premium draws, medium otherwise.
// Safety/Limits: size 0 whenever action function checks; no size auto-converts to jam.
##f$cc_cbet_iso_hu_limper_ip_size_id##
When !f$cc_cbet_iso_hu_limper_ip_action Return 0 Force
When f$cc_flop_dynamic_lowmid_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_premium_draw) Return 3 Force
When f$cc_flop_dynamic_lowmid_parent Return 2 Force
When f$cc_flop_dynamic_high_parent Return 2 Force
When f$cc_flop_static_lowmid_parent && (f$cc_cbet_flop_very_strong_value || f$cc_cbet_flop_overpair || f$cc_cbet_flop_premium_draw) Return 2 Force
When f$cc_flop_static_lowmid_parent Return 1 Force
When f$cc_flop_static_high_parent || f$cc_flop_paired_parent Return 1 Force
When Others Return 2 Force
