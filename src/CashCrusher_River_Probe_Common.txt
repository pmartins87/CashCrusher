// Purpose: source completed River = straight or flush possible on board/runout.
// Source: mature DeepCrusher `f$river_Completed`.
// Provenance: T.
##f$cc_river_probe_completed##
FlushPossible || StraightPossible

// Purpose: paired River board, used by source bad-board/value splits.
// Source/Provenance: T OpenPPL board state.
##f$cc_river_probe_paired##
PairOnBoard

// Purpose: exact count of public broadway ranks across the five-card River board.
// Source: DeepCrusher `f$board_2BW/f$board_3BW` classify >=2 broadways.
// Source/Provenance: T/A equivalent arithmetic over persistent board-card ranks.
##f$cc_river_probe_board_broadway_count##
(FirstFlopCard >= 10 ? 1 : 0) +
(SecondFlopCard >= 10 ? 1 : 0) +
(ThirdFlopCard >= 10 ? 1 : 0) +
(TurnCard >= 10 ? 1 : 0) +
(RiverCard >= 10 ? 1 : 0)

// Purpose: exact source River board class on which native 3wBBvBTN high-air
// abandons the bluff: paired OR any Ace OR at least two broadway board cards.
// Source: DeepCrusher `f$board_BadToBluffRiver`.
// Source/Provenance: T/A direct mechanical translation.
##f$cc_river_probe_bad_to_bluff_board##
IsRiver && (PairOnBoard || board$A || f$cc_river_probe_board_broadway_count >= 2)

// Purpose: conservative exact-two-pair contribution subset. Board-only two pair
// is excluded rather than pretending full equivalence to CF7_ExactTwoPair.
// Source/Provenance: A conservative translation.
##f$cc_river_probe_contributed_exact_two_pair##
HaveTwoPair && !TwoPairOnBoard

// Purpose: literal contributed set, directly available without CF7 reconstruction.
// Source/Provenance: T OpenPPL HaveSet; conservative subset of source real-trips.
##f$cc_river_probe_source_set##
HaveSet

// Purpose: literal nuts subset. It is intentionally narrower than CF7_NutClass;
// no missing nut-class semantics are fabricated.
// Source/Provenance: T/A conservative translation.
##f$cc_river_probe_literal_nuts##
HaveNuts

// Purpose: current no-made/no-frontdoor class used by source missed draw/high-air
// Probe branches after historical flop X/C and Turn X/X.
// Source/Provenance: A cleaned CashCrusher hand taxonomy.
##f$cc_river_probe_air##
IsRiver && f$cc_air_no_frontdoor
