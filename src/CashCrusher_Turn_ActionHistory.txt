// ============================================================================
// CashCrusher_Turn_ActionHistory.txt
// Gate 02N — executed TURN-action provenance for River routing
// ============================================================================
// Purpose:
//   Preserve the difference between a Turn CBet opportunity/plan and what
//   OpenHoldem actually executed. River strategy consumes CLOSED round-3 history;
//   no `user_*` pre-action marker is allowed to prove that Hero really bet.
//
// Runtime findings from project OpenHoldem source:
//   * turn = betting round 3; river = round 4;
//   * didchec/call/rais/betsize/alliround3 are action COUNTERS internally;
//   * successful BetPot-family actions register as `betsize` history;
//   * OpenPPL RaiseBy percentage actions execute through numeric betsize/swag;
//   * BetMax registers as `allin` history;
//   * lastraised3 is the stable previous-street final aggressor once river begins.
//
// Provenance:
//   T = OpenHoldem closed-round action history + persistent user-variable semantics.
//   A = Gate01N final-action repair carried one street forward.
//   P = CashCrusher turn-state/family/live-mask snapshot for future River routing.
//
// OpenPPL safety:
//   Flat complete WHENs only. `user_*` variables written before action are plan /
//   provenance only. Actual execution requires did*round3 + final-aggressor proof.
// ============================================================================
