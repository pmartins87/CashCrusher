// -----------------------------------------------------------------------------
// RFS.01 — current River source hand classes
// -----------------------------------------------------------------------------

// Purpose: source TBP top-pair threshold: current real TP with at most four
// better kicker ranks.
// Source: CrusherTBP `NumberOfBetterKickers <= 4` River-Float value rule.
// Provenance: A direct source-shaped descriptor over T kicker reconstruction.
##f$cc_river_float_source_top_pair_top4##
f$cc_river_top_pair && f$cc_number_better_kickers <= 4

// Purpose: conservative literal-nuts subset used to preserve mature DeepCrusher
// precedence on super-completed boards.
// Source: mature DeepCrusher evaluates `CF7_NutClass` before its 2P+ branch.
// Provenance: A conservative translation using T/OpenPPL `HaveNuts`; this may be
// narrower than CF7_NutClass and therefore never manufactures extra thin value.
##f$cc_river_float_source_literal_nuts##
f$cc_river_float_opportunity && HaveNuts

// Purpose: constrain the generic TBP/DeepCrusher value ladder to player-field
// sizes that existed in the supplied Spin source.
// Source: Crusher/DeepCrusher environment is at most three players.
// Provenance: A source-domain guard; six-max 4+ way/origin states move to Gate06C.
// Safety: a hand that began flop 4+ way is not treated as source-equivalent just
// because folds later leave two or three players on the river.
##f$cc_river_float_source_general_domain_supported##
f$cc_river_float_opportunity &&
f$cc_flop_entry_count >= 2 &&
f$cc_flop_entry_count <= 3 &&
nplayersplaying >= 2 &&
nplayersplaying <= 3

// Purpose: general source value owner after canonical River-Float history.
// Source: CrusherTBP broad value rule, contribution-corrected in DeepCrusher.
// Provenance: A source/manual-review baseline inside source-sized HU/3way fields.
// Six-max 4+ origin/current fields are deliberately not claimed by this source
// function and are reviewed separately in Gate06C.
##f$cc_river_float_source_general_value_action##
When !f$cc_river_float_source_general_domain_supported Return false Force
When f$cc_river_float_source_literal_nuts Return true Force
When f$cc_river_two_pair_plus Return true Force
When f$cc_river_overpair Return true Force
When f$cc_river_float_source_top_pair_top4 Return true Force
When Others Return false Force

// Purpose: mature-source sizing for the general River-Float value ladder.
// Source: DeepCrusher River Float value refinement.
// Provenance: A direct source sizing; literal nuts are kept 75 before the
// super-completed 2P+ reduction to 50.
##f$cc_river_float_source_general_value_size_id##
When !f$cc_river_float_source_general_value_action Return 0 Force
When f$cc_river_float_source_literal_nuts Return f$cc_river_size_75_id Force
When f$cc_river_two_pair_plus && f$cc_river_super_completed Return f$cc_river_size_50_id Force
When f$cc_river_two_pair_plus Return f$cc_river_size_75_id Force
When f$cc_river_overpair Return f$cc_river_size_50_id Force
When f$cc_river_float_source_top_pair_top4 Return f$cc_river_size_50_id Force
When Others Return 0 Force

// Source: mature DeepCrusher explicitly returns false for 3wBTNvSB + NoMadeHand.

f$cc_hero_pos_id = 4 &&

f$cc_river_no_made
