// Purpose:
//   Fill ordinary one-raise SRP Turn-Float states not decided by exact Gate05B
//   source branches. Histories remain separate: call-flop/missed-2Bar, CBet-XR-
//   call, and FlopFloat-XR-call are not interchangeable range states.
//
// Source boundary:
//   DeepCrusher has useful position/history principles but no complete 100bb
//   six-max tree for these states. Betting policy below is therefore P-heavy.
//
// Professional principles used (P):
//   * IP can value/protection bet more often after OOP aggression stops;
//   * XR-call histories are materially more selected than a simple flop call;
//   * current strength overrides stale flop class;
//   * completed/4-card runouts reduce thin one-pair value;
//   * pure-air stabs require a narrow scare-card/high-card selector;
//   * post-multiway/current-multiway histories are tightened sharply.
//
// Safety:
//   Exact source coverage/locks always win. No HandPower/random tail and no
//   stackoff or BetMax decision appears here.
// ============================================================================
