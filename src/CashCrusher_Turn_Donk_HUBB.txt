// Source hierarchy:
//   T = `11- NOVO CRUSHFEST HUBB` direct Turn Donk answers:
//       * TP+ donk if Villain 2barrels below 45%;
//       * good draws OESD/FD/2mOC+GS -> X/C Turn;
//       * weak GS and air -> Donk 25%;
//       * pair+draw -> X/C;
//       * MP/BP after big flop CBet: completed -> X/F, non-completed ->

//       low-2bar exploit statistic.

//         two players preflop. This descendant is never labelled direct T.

//   The current attack layer cannot reconstruct the flop bet SIZE that Hero

//   boundary therefore fail closed until future Flop defense records exactly one
//   of `user_cc_flop_donk_hubb_called_gt50` / `_called_le50`.
//
// Safety:
//   No ISO, 3BP/squeeze, 4BP, BTN-v-blind or generic OOP-HU caller enters here.
//   No stackoff, jam, HandPower, random or generic commitment threshold appears.
//   River give-up / River Donk instructions are history for later streets, not
//   permission to smuggle a future action into this Turn node.
