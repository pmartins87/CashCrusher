// Gate 05G.1 — OpenPPL runtime adapter for reviewed Turn Float sizes

// Purpose:
//   Translate strategic Turn-Float size IDs into exact OpenPPL actions. This file
//   does not decide whether to Float and does not decide strategic commitment.
//
// Runtime basis:
//   * `RaiseBy 25%` for exact quarter-pot;
//   * native BetThirdPot / BetHalfPot / BetThreeFourthPot / BetPot;
//   * canonical Turn Float has AmountToCall=0 on Hero's first Turn action.
//
// Source/Provenance:
//   T = verified OpenPPL percentage/native action semantics.
//   A/P = reviewed Gate05 25/33/50/75/100 palette.
// ============================================================================

// Purpose: positive reviewed Turn Float owns one valid runtime size.
// Source/Provenance: P engineering guard over A/P strategy router.
##f$cc_turn_float_runtime_size_ready##
When !f$cc_turn_float_router Return false Force
When !f$cc_turn_float_family_exclusive Return false Force
When !f$cc_turn_float_size_consistent Return false Force
When f$cc_turn_float_size_id >= 1 && f$cc_turn_float_size_id <= 5 Return true Force
When Others Return false Force

// Purpose: strategic size ID to exact pot fraction for stack geometry/tests.
// Source/Provenance: A/P frozen Turn-Float palette.
##f$cc_turn_float_requested_pot_fraction##
When !f$cc_turn_float_runtime_size_ready Return 0 Force
When f$cc_turn_float_size_id = 1 Return 0.25 Force
When f$cc_turn_float_size_id = 2 Return 0.333 Force
When f$cc_turn_float_size_id = 3 Return 0.50 Force
When f$cc_turn_float_size_id = 4 Return 0.75 Force
When f$cc_turn_float_size_id = 5 Return 1.00 Force
When Others Return 0 Force

// Purpose: exact OpenPPL sizing action before natural all-in equivalence.
// Source/Provenance: T runtime adapter over A/P strategy size ID.
##f$cc_turn_float_requested_betsize##
When !f$cc_turn_float_runtime_size_ready Return 0 Force
When f$cc_turn_float_size_id = 1 RaiseBy 25% Force
When f$cc_turn_float_size_id = 2 Return BetThirdPot Force
When f$cc_turn_float_size_id = 3 Return BetHalfPot Force
When f$cc_turn_float_size_id = 4 Return BetThreeFourthPot Force
When f$cc_turn_float_size_id = 5 Return BetPot Force
When Others Return 0 Force

// Purpose: positive action resolves to exactly one positive pot fraction.
// Source/Provenance: P runtime invariant over T/A mapping.
##f$cc_turn_float_runtime_mapping_valid##
When !f$cc_turn_float_router Return f$cc_turn_float_requested_pot_fraction = 0 Force
When !f$cc_turn_float_runtime_size_ready Return false Force
When f$cc_turn_float_requested_pot_fraction <= 0 Return false Force
When f$cc_turn_float_size_id < 1 || f$cc_turn_float_size_id > 5 Return false Force
When Others Return true Force
