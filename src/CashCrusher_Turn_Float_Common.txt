// TFC.01 — current no-made split
// -----------------------------------------------------------------------------

// Purpose: no made hand with a real turn frontdoor straight/flush draw.
// Source: DeepCrusher `NoMadeHand && Gutshot_or_BetterFDSD` direct Turn-Float
// branches; CashCrusher uses contribution-aware real draw primitives.
// Provenance: T/A exact strategic category replacement.
##f$cc_turn_float_current_real_draw##
f$cc_hand_no_made && f$cc_real_frontdoor_draw

// Purpose: no made hand without a real frontdoor draw.
// Source: DeepCrusher `hand_Air` / A-K-high-backdoor-air Turn-Float family.
// Provenance: T/A cleaned source category; includes high-card air intentionally.
##f$cc_turn_float_current_air##
f$cc_hand_no_made && !f$cc_real_frontdoor_draw

// Purpose: reconstruct the source `user_AirCalledRaiseOTF` domain without using
// the legacy user variable. In source it was written when Hero had NO MADE HAND
// plus Gutshot-or-better draw before calling a BTN flop X/R.
// Source/Provenance: A exact marker-domain reconstruction from Gate01 snapshot.
// Safety: flop pure-air CBet/XR/call is not silently treated as that source state.
##f$cc_turn_float_btnadv_flop_draw_marker_analog##
user_cc_flop_cbet_had_no_made &&
(user_cc_flop_cbet_had_premium_draw || user_cc_flop_cbet_had_good_draw || user_cc_flop_cbet_had_weak_draw)

// Purpose: flop draw-marker domain that has improved to a current made hand.
// Source: current audited DeepCrusher lets the residual `user_AirCalledRaiseOTF`
// branch bet 50 after excluding current air/A-high and still-live real draws.
// Provenance: A current-DeepCrusher behavior; primary BTN Advanced PDF is silent
// on the exact made-improvement sizing, so this must not be labelled primary-source.
##f$cc_turn_float_btnadv_made_improvement##
f$cc_turn_float_btnadv_flop_draw_marker_analog && f$cc_hand_pair_or_better
