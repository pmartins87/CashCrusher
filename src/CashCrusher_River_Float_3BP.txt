// Gate 06E — plain 3BP and squeeze River Float
// ============================================================================
// Purpose:
//   Review River-Float states in two-raise pots while preserving whether Hero /
//   the actual Turn aggressor came from the opener, final 3bettor/squeezer,
//   pre-3bet coldcaller or post-3bet coldcaller range.
//
// Source boundary:
//   DeepCrusher's `f$river_Raise_GotRaised` can route preflop-reraised histories
//   with LAST/MIDDLE + nothing-to-call into `f$move_river_floatbet`.  The move
//   function itself has NO dedicated deep-stack 3BP/squeeze value/bluff table.
//   Its portable positive source is therefore only Gate06B's generic River-Float
//   value ladder inside the <=3-player source domain.
//
// Provenance:
//   T = Gate06A closed turn-call parent + OpenHoldem raiser/caller history.
//   A = DeepCrusher GotRaised river ownership + Gate05/FinalAggressor chronology.
//   P = plain-3BP/squeeze range decomposition, selected-range checks and 4+ origin
//       robust-value adaptation.
//
// Safety:
//   * plain 3BP != squeeze;
//   * opener != pre-3bet coldcaller != post-3bet coldcaller != final 3bettor;
//   * no generic missed-draw bluff without a Turn-call draw/blocker snapshot;
//   * current HU after a multiway flop never becomes a clean-HU range by folding;
//   * no HandPower/random/BetMax/commitment/raise-response logic lives here.
// ============================================================================
