# Gate 03D — Isolation-pot River CBet

Status: **P-heavy River policy boundary frozen**.

DeepCrusher has no clean dedicated deep-stack `isolate -> flop CBet -> Turn CBet -> River CBet` tree. Its `GotRaised_Or_Isolated` history groups multiple ownership paths, so using those downstream rules as a literal ISO triple-barrel source would create false provenance.

CashCrusher therefore carries forward Gate02 family 9 and reconstructs the current River field from the original pre-raise-limper and post-raise-coldcaller masks.

## Range distinctions

- **original limper**: generally the widest/weakest ISO continue range; clean River one-pair value can be somewhat broader, especially IP;
- **post-raise coldcaller**: more selected/condensed; medium one-pair and bluffing tighten;
- **Turn was multiway -> River HU**: the sole survivor called a multiway second barrel and is more selected than a flop/Turn-HU caller;
- **River still multiway**: value-heavy, deepest-effective SPR controls any field-wide low-SPR relaxation.

## River bluffing

The initial deterministic baseline allows only a narrow missed-premium-draw/high-pressure blocker bluff versus an original limper in a clean Turn-HU/IP lineage. It does not authorize generic air versus coldcallers or any multiway River bluff.

This is a P selection rule, not a solver frequency.

## Stack-depth rule

TP/OP River value bets do not authorize calling a raise or playing stacks. Historical short-stack commitment mechanisms remain independently reviewable. A future River sizing layer may convert a requested value size to a natural all-in if it already reaches Hero/effective stack.
